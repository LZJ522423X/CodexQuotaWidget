## 当前阶段与生效门槛

当前为 **Blocked：真实 SIWC 完整正文验收未通过**。最新请求身份、真实/离线验证结果和停止点统一维护在 [AI-CONTROL-CENTER-STATUS.md](AI-CONTROL-CENTER-STATUS.md)，不在本约束中复制逐轮状态。所有历史请求的 claim、Ticket、机器可读报告及任务证据继续保留，不重发。当前不启动自动循环，不自动接管开发。

单条正文通过后，也不能立即接管。必须先由小组件自己的 WorkflowConnector 完成独立、受控的真实端到端验收，且六项全部具有可核验、持久化的证据：

1. 小组件向独立 GPT 会话发送请求，账户、Backend、模型及会话身份匹配。
2. 小组件取得 GPT 完整正文及合法完成状态，关联本轮请求，不能使用引用、窗口代读或根代理转发替代。
3. GPT 建议在原任务授权内，正确绑定 TaskId、RequestId、项目、Codex Session、轮次及允许的文件范围后，交给 Codex。
4. Codex 执行获准任务，返回真实执行结果；本地固定检查和证据验证通过。
5. 小组件把已验证的真实执行结果及检查证据交给 GPT 复核。
6. 小组件读取并验证完整复核正文与完成状态，正确关联任务、请求编号、轮次和执行证据，作出继续/完成/阻断判断。

连接成功、MCP 初始化成功、进程存在、HTTP 200、离线测试通过、Codex 自报成功、编译成功或单条正文成功，均不等同于六项真实闭环验收通过。实验正文的一次性 Unknown 额度例外不得沿用到正常循环。

## 全链路真实通过之后

六项通过并保存真实验收证据后，在既有授权范围和安全门禁内，立即由 AI Control Center 自身继续当前开发任务。此切换已获用户条件授权，不再要求用户手动转发中间报告，也不让外部根代理代替小组件搬运消息。

执行顺序固定为：GPT 建议 → 授权与项目核对 → Codex 执行 → 固定检查与实际结果验证 → GPT 复核 → 下一轮获准任务或结束。

- 每轮持久化任务状态、请求及 Session 身份、执行/检查/复核证据和恢复记录。
- 不重复已确认完成的步骤；旧结果不得覆盖当前任务。结果不确定时先核验，不能盲目重发。
- 连接中断、正文无法读取、额度不足/Unknown、身份或证据不足时安全暂停/Blocked，保留进度。
- 保留去重、轮次、预算和重复错误保护；目标达成后结束，不能为保持循环自行增加任务。
- 用户要求确认或原权限不足时暂停；不得扩大项目、文件范围、账户、费用或高风险操作权限。
- 不降低 Unknown、Blocked、额度、授权、身份、项目和证据门禁。
- 不修改 Codex 核心配置、AGENTS.md、Skill、网络/代理或生产版，不自动推送 GitHub。
